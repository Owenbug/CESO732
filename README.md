# Formulario personal para citas de tatuaje

Sitio estático preparado para GitHub Pages.

## Archivos

- `index.html`: estructura del formulario.
- `styles.css`: diseño, colores y adaptación móvil.
- `app.js`: navegación, validaciones y confirmación.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `citas-tatuaje`.
2. Sube los cuatro archivos de esta carpeta a la raíz del repositorio.
3. Abre **Settings > Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/ (root)` y guarda.
6. GitHub mostrará una dirección similar a:
   `https://usuario.github.io/citas-tatuaje/`

## Estado actual

Esta entrega contiene el formulario visual funcional. La confirmación se muestra
en pantalla, pero todavía no envía ni guarda información. La integración con
Google Sheets, Drive y Calendar se agregará mediante Google Apps Script después
de definir la cuenta, disponibilidad y reglas del tatuador.
